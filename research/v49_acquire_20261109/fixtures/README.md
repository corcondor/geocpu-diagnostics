# Test fixtures (tiny, public rows)

Source: Hugging Face datasets-server `first-rows` API (read-only JSON, <= 100 rows per call), fetched 2026-11-09 with
`make_fixtures.py --fetch`; rows selected with `make_fixtures.py` (one row per distinct converter outcome, smallest first,
<= 20 rows and a byte budget per dataset, < 100 KB in total). The full datasets are NOT downloaded locally.
Rows are real and unmodified; only the container layout differs where noted. Attribution and licences of the original data:

- `coding_fixture.json` - llm-jp/Synthetic-JP-EN-Coding-Dataset (Apache-2.0; LLM-jp, Kiyomaru and Kodama; subset of Aratako/Synthetic-JP-EN-Coding-Dataset-801k). List of `{"messages": [{role, content}, ...]}`.
- `tengentoppa_fixture.jsonl` - DeL-TaiseiOzaki/Tengentoppa-sft-qwen2.5-32b-reasoning-100k (Apache-2.0; generated by Qwen2.5-32B-Instruct). Fields instruction / reasoning / initial_answer / refined_answer.
- `jaquad_train_fixture.json` - SkelterLabsInc/JaQuAD, train split (CC BY-SA 3.0; So, Byun, Kang, Cho, 2022; Japanese Wikipedia contexts). The first-rows view (one record per question) is re-nested into the raw file layout `{"data": [{"title", "paragraphs": [{"context", "qas": [{id, question, question_type, answers: [{text, answer_start, answer_type}]}]}]}]}` that `data/train/jaquad_train_*.json` uses (layout taken from the dataset's `JaQuAD.py` loader).
- `hotpot_fixture.json` - hotpotqa/hotpot_qa, config `distractor`, train split (CC BY-SA 4.0; Yang et al., 2018). Rows as in the parquet (`supporting_facts` and `context` are dicts of lists).
- `toolace_fixture.json` - Team-ACE/ToolACE (Apache-2.0 per the dataset card; Liu et al., 2024, arXiv:2409.00920). List of `{"system", "conversations": [{from, value}]}` as in `data.json`.
- `wizard_fixture.json` - llm-jp/wizardlm8x22b-logical-math-coding-sft-ja (Apache-2.0; LLM-jp; texts generated with WizardLM-2-8x22B). List of `{"messages": [...]}`.

No validation / dev / test rows are included.
